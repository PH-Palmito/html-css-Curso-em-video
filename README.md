# 🌐 Meus Primeiros Passos com HTML e CSS

Este repositório reúne os exercícios e projetos que desenvolvi durante o curso de **HTML5 e CSS3** do professor **Gustavo Guanabara** pelo [Curso em Vídeo](https://www.cursoemvideo.com/). Aqui foi onde tudo começou! 🚀

---

## 📚 Sobre o curso

O curso apresenta os fundamentos de HTML e CSS, focando em:

- Estruturação de páginas com HTML5
- Estilização com CSS3
- Semântica
- Boas práticas para iniciantes
- Organização de arquivos e links

## 📁 O que tem nesse repositório?

- 📄 Páginas HTML básicas (com tags de texto, imagem, listas, links e muito mais)
- 🎨 Primeiros estilos com CSS
- 🌍 Testes com links, vídeos e mídias
- 📦 Estruturação de pastas como ensinado no curso
